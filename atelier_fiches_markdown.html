01 / Personnaliser

Le symbole choisi marque les titres de section.

02 / Markdown

Utilise # pour le titre, *italique* pour le sous-titre, ## ou ### pour les sections, > pour les citations et --- pour les séparateurs. Les listes et le gras fonctionnent aussi. La ligne en italique ou préfixée par -# après le titre devient le sous-titre. Le modèle complet est personnalisable : remplace les champs entre crochets et supprime les rubriques inutiles.

03 / Modèles et export

Le brouillon n’est pas enregistré automatiquement. Exporte-le pour le garder. Pour le PDF, choisis « Enregistrer au format PDF » et active « Graphiques d’arrière-plan » dans la boîte d’impression de ton navigateur. Les pages A4 se répartissent automatiquement.
